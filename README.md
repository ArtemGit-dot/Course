# Course
Course App — это Android-приложение, демонстрирующее реализацию современного подхода к архитектуре и навигации. Оно построено с использованием Clean Architecture, паттерна MVVM, и таких инструментов как Navigation Component, RecyclerView, Retrofit и Dagger.

🛠 Стек технологий
Clean Architecture — чёткое разделение слоёв: Presentation, Domain, Data

MVVM — управление UI через ViewModel и LiveData

Navigation Component — безопасная и удобная навигация между экранами

RecyclerView — отображение списков курсов и избранного

Retrofit — сетевые запросы к API

Dagger 2 — внедрение зависимостей

📱 Основные экраны
1. Onboarding
Горизонтальная прокрутка с информацией о приложении

После последнего экрана — переход к авторизации

2. Авторизация
Поле ввода email (валидируется на корректность)

Поле ввода пароля

Переход к главному экрану при успешной авторизации

3. Экран курсов
Список курсов, полученных с API

У каждого курса есть флажок (в правом верхнем углу)

При нажатии на флажок — курс добавляется в избранное

4. Избранное
Отображает список курсов, добавленных пользователем

Картинки курсов загружаются из resources/drawable, так как не приходят с API
